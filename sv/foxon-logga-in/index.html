Fox On Logga in

Så loggar du in på ditt konto hos Fox On

För att logga in på ditt konto hos Fox On är processen enkel och kan göras både via webbläsaren och via mobila enheter:

  1. Gå till plattformen: gå till Fox Ons inloggningssida och klicka på "Logga in" eller "Login", vanligtvis längst upp till höger på sidan.
  2. Ange dina inloggningsuppgifter: skriv in din registrerade e-postadress och ditt lösenord. Om du använder en egen dator kan du kryssa i alternativet för att förbli inloggad.
  3. Autentisering (om aktiverad): om du har aktiverat tvåfaktorsautentisering (2FA) behöver du ange verifieringskoden som skickas via SMS, e-post eller genereras av en app för autentisering.
  4. Åtkomst beviljad: efter verifieringen omdirigeras du till ditt kontos kontrollpanel, där du kan följa investeringar, transaktioner och utforska plattformens alla verktyg.
Registrera dig hos mäklaren

Glömt lösenordet: vad gör du?

Om du inte kommer ihåg ditt lösenord erbjuder själva inloggningssidan ett alternativ för återställning.

Se steg för steg:

  1. Klicka på "Glömt lösenordet";
  2. Ange din registrerade e-postadress;
  3. Följ instruktionerna som skickas för att återställa ditt lösenord;
  4. Skapa ett nytt, starkt lösenord och gå tillbaka till inloggningssidan.

Processen brukar vara snabb och automatiserad. Om du inte får e-postmeddelandet är det värt att kontrollera skräppostmappen.

Problem med att logga in på Fox On?

Om du fortfarande har problem med att komma åt ditt konto efter att ha följt stegen ovan kan några alternativ hjälpa:

  • Kontrollera din internetanslutning;
  • Rensa webbläsarens cacheminne och försök igen;
  • Uppdatera din webbläsare till en nyare version;
  • Använd en annan enhet eller nätverk för att utesluta lokala problem;
  • Kontakta Fox Ons support om felet kvarstår.

Mäklaren erbjuder support via e-post och via specifika kanaler direkt på plattformen. Kom ihåg att välja ett starkt lösenord, med bokstäver, siffror och symboler.

Support vid åtkomstproblem

Om du har svårigheter att logga in och inte kan lösa det med stegen ovan, kontakta supportteamet:

  • Livechatt: tillgänglig direkt på plattformen och i appen;
  • Kontoansvarig dygnet runt: suporte@foxonivesting.com.br
  • Hjälpcenter: med vanliga frågor och guider.

Supporten är snabb och effektiv, med personal som är förberedd att hantera alla situationer som rör din åtkomst.
